Icons

An icon for every slice.

Letters, an emoji, a Windows symbol or your own logo, on a shape and in your colours. Make it here, see it at the size the ring really draws it, download the picture and drop it on the icon window in RadialDeck. Then keep it, or give it to everybody.

My slice
My slice

The two small tiles are the icon at the 28 pixels a slice draws it, on a dark and a light ring. If it reads there, it reads everywhere.

In RadialDeck: Settings → a slice → the … next to Icon → drop the file on that window. It goes into My icons and stays there.

What is on it

The same symbols Windows uses. They draw here only on a Windows PC, because the font ships with Windows.

From everyone else

Icons other people made.

Like the themes, the icons are a folder in a public repository: no account, nothing to sign up for. Download one and drop it on the icon window in RadialDeck.

How to send yours

  1. Make it above and press Download the picture. A 256×256 PNG with a transparent background works best.
  2. Press Share it on GitHub. It opens the upload page of the icons folder: drag the picture onto it.
  3. Choose Propose changes. GitHub turns it into a pull request; you do not need to install anything.
