A radial menu for GitHub Desktop.

RadialDeck gives GitHub Desktop a ring of its own: hold the hotkey while GitHub Desktop is in front, flick toward a slice and let go. The gallery has 9 ready-made actions for it, among them commit, push, pull. Everywhere else your usual ring stays as it is.

9 actions, ready to add

  • CommitCommit staged changes
  • PushPush to remote
  • PullPull from remote
  • New branchCreate new branch
  • Pull requestCreate pull request on GitHub
  • BranchesShow branch list
  • Open editorOpen repo in external editor
  • Show in ExplorerShow repo in Explorer
  • TerminalOpen repo in command line

How to add them

Open RadialDeck Settings, go to the gallery, search for “GitHub Desktop” and add the actions you want. If GitHub Desktop is installed when you first start RadialDeck, the Welcome window can suggest them for you.

A ring that appears only in GitHub Desktop is part of Pro, with a 14-day trial built in. In Free you can put the same actions on one of your two rings.
