PT

A radial menu for PowerToys.

RadialDeck gives PowerToys a ring of its own: hold the hotkey while PowerToys is in front, flick toward a slice and let go. The gallery has 7 ready-made actions for it, among them microsoft PowerToys: PowerToys Run, microsoft PowerToys: Command Palette, microsoft PowerToys: Color Picker. Everywhere else your usual ring stays as it is.

7 actions, ready to add

  • Microsoft PowerToys: PowerToys RunOpen the quick launcher
  • Microsoft PowerToys: Command PaletteOpen Command Palette
  • Microsoft PowerToys: Color PickerPick a color from the screen
  • Microsoft PowerToys: Text ExtractorOCR any text on screen
  • Microsoft PowerToys: Always On TopPin the active window on top
  • Microsoft PowerToys: Screen RulerMeasure pixels on screen
  • Microsoft PowerToys: Advanced PasteOpen the Advanced Paste window

How to add them

Open RadialDeck Settings, go to the gallery, search for “PowerToys” and add the actions you want. If PowerToys is installed when you first start RadialDeck, the Welcome window can suggest them for you.

A ring that appears only in PowerToys is part of Pro, with a 14-day trial built in. In Free you can put the same actions on one of your two rings.
