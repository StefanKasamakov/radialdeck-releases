A radial menu for Visual Studio.

RadialDeck gives Visual Studio a ring of its own: hold the hotkey while Visual Studio is in front, flick toward a slice and let go. The gallery has 9 ready-made actions for it, among them visual Studio 2022: Search, visual Studio 2022: Debug, visual Studio 2022: Run. Everywhere else your usual ring stays as it is.

How to add them

Open RadialDeck Settings, go to the gallery, search for “Visual Studio” and add the actions you want. If Visual Studio is installed when you first start RadialDeck, the Welcome window can suggest them for you.

A ring that appears only in Visual Studio is part of Pro, with a 14-day trial built in. In Free you can put the same actions on one of your two rings.
