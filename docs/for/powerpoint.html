A radial menu for PowerPoint.

RadialDeck gives PowerPoint a ring of its own: hold the hotkey while PowerPoint is in front, flick toward a slice and let go. The gallery has 10 ready-made actions for it, among them start slideshow, slideshow from current slide, new slide. Everywhere else your usual ring stays as it is.

10 actions, ready to add

  • Start slideshowPresses F5.
  • Slideshow from current slidePresses Shift+F5.
  • New slidePresses Ctrl+M.
  • DuplicateDuplicate selected slide / object
  • GroupGroup selected objects
  • LinkInsert hyperlink
  • Selection paneShow Selection pane
  • Black screenBlack screen during show
  • End showEnd the slide show
  • Save as PDFExport dialog with PDF chosen.

How to add them

Open RadialDeck Settings, go to the gallery, search for “PowerPoint” and add the actions you want. If PowerPoint is installed when you first start RadialDeck, the Welcome window can suggest them for you.

A ring that appears only in PowerPoint is part of Pro, with a 14-day trial built in. In Free you can put the same actions on one of your two rings.
