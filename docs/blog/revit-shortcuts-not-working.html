Revit keyboard shortcuts not working? The input language, KeyboardShortcuts.xml and other causes

Why Revit's two-letter shortcuts stop working, from the Windows input language to a damaged KeyboardShortcuts.xml after an update, and how to fix each one.

Revit shortcuts work differently from most Windows programs. Instead of Ctrl combinations, Revit uses short letter sequences: W A for Wall, D R for Door, A L for Align, T R for Trim. You type the letters in the drawing area and Revit runs the command. That design explains most of the ways it breaks.

1. The Windows input language is not English

This is the most common cause when shortcuts suddenly stop working for no visible reason. Revit matches the letters you type against its list of shortcuts. If Windows has switched to another input language, the same keys type other letters. On a Russian or Bulgarian layout, W A comes out as Cyrillic letters, which match no shortcut, so nothing happens.

The switch is easy to make without noticing: Win+Space and Alt+Shift both change the layout, and Windows can keep a different layout per window.

Check: look at the language indicator next to the clock while Revit is in front.

Fix: press Win+Space until it shows ENG (or the language your shortcuts were made for). If you type in two languages all day, consider giving yourself a habit of switching back before you model, or removing layouts you rarely use in Settings > Time & language > Language & region.

2. The drawing area does not have focus

Revit reads shortcut letters when the drawing area has focus. If the cursor is in the Properties palette, the Project Browser or a text box, the letters go there instead.

Check: click once in an empty part of the view, press Esc twice to clear any command, and type the shortcut again.

3. KeyboardShortcuts.xml is damaged or missing

Revit keeps your shortcuts in a file called KeyboardShortcuts.xml in your user profile:

%APPDATA%\Autodesk\Revit\Autodesk Revit 20xx\

(with your version in place of 20xx). After an update, a crash, or a sync of a profile from another computer, this file can lose entries or stop loading. Autodesk's support article on missing keyboard shortcuts describes this case.

Fix, as Autodesk describes it:

  1. Close Revit.
  2. In the folder above, rename KeyboardShortcuts.xml to something like Backup_KeyboardShortcuts.old.
  3. Start Revit. It creates the file again with the default shortcuts.

If you had custom shortcuts, export them first from View > User Interface > Keyboard Shortcuts (or type K S) with Export, and bring them back after the reset with Import in the same dialog. Offices that share one shortcut file can keep the exported XML on a network drive and import it on each computer.

4. A shortcut was changed or removed

Shortcuts are easy to change and hard to notice: someone assigns W A to another command, or a shared office file replaces yours.

Check: open Keyboard Shortcuts (K S), search for the command and see which keys it has. Then search by the keys themselves: if the same letters are assigned to two commands, the one that runs may not be the one you expect, so remove the assignment you do not need.

5. An add-in or another program takes the keys

Revit add-ins can register their own commands, and those commands can be given shortcuts in the same dialog, so an add-in command can end up on the letters you expect for a built-in tool. System-wide tools are the other suspect: clipboard managers, screen recorders, translation tools and keyboard utilities can take a key before Revit sees it.

Check: if shortcuts fail only with a certain add-in installed, remove or disable that add-in according to its maker's instructions and test again. For system tools, close tray programs one at a time and try the shortcut after each.

6. Shortcuts that end with a modifier or a function key

Most Revit shortcuts are plain letters, but some built-in ones and many custom ones use Ctrl, Shift or the function keys. On a laptop, the top row may send brightness and volume first. Hold Fn with the key, or turn on Fn Lock (on many keyboards Fn+Esc), so that F8 reaches Revit as F8.

Where a radial menu helps, and where it does not

RadialDeck is the radial menu for Windows that we make. When Revit is in front, the same hotkey opens a Revit ring with commands such as Wall, Door, Window, Align, Trim, Move, Copy and Tag by category. The gallery has 20 Revit actions. You flick toward a command instead of remembering its two letters.

To be precise about how it works: the Revit recipes in our gallery press the same keys you would, as key strokes (W then A for Wall). That has two consequences:

  • A ring does not fix cause 1. If Windows is set to a Cyrillic layout, those key strokes produce Cyrillic letters inside Revit, exactly as your own typing does, and the command does not run. Switch the input language to English first.
  • A ring does not get past causes 3 and 5 either. A damaged shortcut file or an add-in that took the letters blocks the ring's keys as it blocks yours. Cause 6 is different: on most laptops Fn Lock is handled inside the keyboard itself, and a slice you set to send F8 sends it to Windows directly.
  • A ring does help with cause 4 and with memory. You no longer need to remember which letters a command has; you pick Tag by category or Section box by name.

If your office uses custom Revit shortcuts, change the slices to send your keys instead. Each slice is a "Send keys" action, and you edit the keys in Settings.

Quick checklist

  1. Language indicator shows ENG? If not, Win+Space.
  2. Click in the view and press Esc twice.
  3. Rename KeyboardShortcuts.xml and restart Revit.
  4. Check the command in Keyboard Shortcuts (K S).
  5. Disable add-ins and close tray tools one at a time.
  6. Use Fn or Fn Lock for shortcuts on function keys.
