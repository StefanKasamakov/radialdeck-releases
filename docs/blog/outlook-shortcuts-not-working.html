Outlook keyboard shortcuts not working? New Outlook and classic Outlook fixes

Why Outlook shortcuts stop working in the new Outlook and in classic Outlook for Windows, which shortcuts differ between them, and how to get each one back.

"Outlook shortcuts stopped working" has two very different answers, because there are two Outlook apps for Windows. Classic Outlook is the long-standing desktop app with the File menu. New Outlook is the newer app with a toggle in the top-right corner, built on the same code as Outlook on the web. They share many shortcuts, not all of them, and they have different settings. Start by finding out which one you are in: if you see File > Options, you are in classic Outlook.

New Outlook: check the keyboard shortcut setting

New Outlook lets you choose which set of shortcuts it uses, or turn shortcuts off completely. If someone picked a different set, or turned them off, your usual keys stop working.

Check: go to Settings > General > Accessibility and look at Keyboard shortcuts. In new Outlook the choices are the Outlook for Windows shortcuts, the Outlook on the web shortcuts, or Turn off keyboard shortcuts. Outlook on the web also offers Gmail-style and Yahoo Mail-style sets.

Fix: pick the set that matches what you learned and select Save. If you came from classic Outlook, choose the Outlook for Windows set.

Shortcuts that differ between the two

Microsoft's list of Outlook keyboard shortcuts covers both apps, and some keys only exist, or only work in some places, in one of them. A few you will notice:

  • Move to a folder: Ctrl+Shift+V in classic Outlook opens Move to Folder. In new Outlook the shortcut is reported to work from the message list but not from an opened message.
  • Mark as read: Ctrl+Q in both.
  • Reply, Reply all, Forward: Ctrl+R, Ctrl+Shift+R, Ctrl+F in both.
  • Send: Ctrl+Enter sends in both. According to answers on Microsoft Q&A, new Outlook has no option to turn off this one shortcut on its own.
  • Quick Steps: a Quick Step can have a shortcut. Classic Outlook offers Ctrl+Shift+1 to Ctrl+Shift+9; new Outlook only Ctrl+Shift+5 to Ctrl+Shift+9, because the lower numbers do other things there.

If one shortcut never worked after a switch, check whether it exists in the app you are using before you troubleshoot anything else.

Classic Outlook: add-ins

Classic Outlook loads COM add-ins for CRM systems, PDF tools, meeting apps and antivirus scanners. Any of them can take a shortcut or slow keyboard handling down.

Check: start Outlook in safe mode. Press Win+R, type outlook.exe /safe and press Enter. If the shortcut works in safe mode, an add-in is the cause.

Fix: go to File > Options > Add-ins, choose COM Add-ins and Go, clear the boxes, restart Outlook, then turn the add-ins back on one at a time until the shortcut stops working again.

The focus is somewhere else

Outlook shortcuts depend on what has focus. Ctrl+Q marks the selected message as read when the message list has focus. In a message you are writing, many keys belong to the editor instead, and a search box or the folder pane takes some keys for itself.

Check: click once on the message list, then try again.

The input language and keyboard layout

Shortcuts that use Ctrl with a letter usually keep working in other keyboard layouts. Two cases do not:

  • Ctrl+Alt is AltGr on many European layouts, so a combination with both Ctrl and Alt can type a character instead of reaching Outlook.
  • Key tips after Alt follow the letters on the ribbon. With a Cyrillic or Greek layout active, the keys type other letters and do not match.

Fix: switch the layout with Win+Space (or Alt+Shift) and watch the language indicator in the taskbar.

Another program grabbed the keys

Tools that register system-wide shortcuts take the keys before Outlook sees them. Clipboard managers often use Ctrl+Shift+V, which is classic Outlook's Move to Folder. Translation and screen-capture tools use Ctrl+Shift and Ctrl+Alt combinations.

Check: close tray programs one at a time and test after each.

Quick checklist

  1. Find out which Outlook you use.
  2. New Outlook: Settings > General > Accessibility > Keyboard shortcuts.
  3. Classic Outlook: start outlook.exe /safe and test.
  4. Click the message list before using list shortcuts.
  5. Check the keyboard layout in the taskbar.
  6. Close tray tools that use Ctrl+Shift combinations.
