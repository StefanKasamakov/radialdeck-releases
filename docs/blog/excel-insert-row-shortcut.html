Excel shortcut to insert a row (and why Ctrl+Plus sometimes does nothing)

The keyboard way to insert a row in Excel for Windows, how to insert several at once, the ribbon route, and the reasons the shortcut fails on laptops and some keyboard layouts.

To insert a row in Excel for Windows, select the row with Shift+Space, then press Ctrl+Shift+Plus. A new, empty row appears above the one you selected.

If you press Ctrl+Shift+Plus with just a cell selected instead of the whole row, Excel opens the Insert dialog and asks what to shift. Choose Entire row and press Enter. Selecting the row first skips that question.

The two steps, in detail

  • Shift+Space selects the entire row of the active cell. Microsoft lists it as "Select an entire row in a worksheet."
  • Ctrl+Shift+Plus is Excel's insert command. With a whole row selected it inserts a row; with cells selected it opens the Insert dialog.

On a full keyboard, Ctrl and the + key on the numeric keypad does the same job without Shift, because the keypad plus is already a plus sign.

Insert several rows at once

Excel inserts as many rows as you have selected:

  1. Click a cell in the row where the new rows should go.
  2. Press Shift+Space to select the row.
  3. Hold Shift and press Down to extend the selection, for example to three rows.
  4. Press Ctrl+Shift+Plus. Three empty rows appear above the selection.

To repeat the last insert somewhere else, move to the new spot and press F4, which repeats the last action.

The ribbon route

Microsoft's documented menu path is Home > Insert > Insert Sheet Rows, which inserts a row above the active cell without selecting the row first. From the keyboard: press and release Alt, then follow the key tips to Home, Insert and Insert Sheet Rows. In the English version of Excel these are H, I and R; in other languages the letters follow the menu names.

You can also right-click the row number and choose Insert.

Deleting a row

The opposite works the same way: Shift+Space to select the row, then Ctrl+Minus to delete it. With only cells selected, Ctrl+Minus opens the Delete dialog instead.

Why the shortcut does nothing

  • Laptop keyboards. On most laptops the plus sign shares a key with =, so "plus" needs Shift. That is why the shortcut is written Ctrl+Shift+Plus: on these keyboards it is really Ctrl, Shift and the = key.
  • A different keyboard layout. On some layouts the plus sign sits on another key or needs AltGr. If the shortcut never fires, the ribbon route (Alt, H, I, R in English Excel) works on any layout.
  • The sheet is protected. Excel will not insert rows into a protected sheet. Unprotect it under Review > Unprotect Sheet.
  • The last rows of the sheet are not empty. Excel cannot push data past the last row of the worksheet, so it refuses to insert. Clear anything far down the sheet, such as stray formatting or values.
  • You are editing a cell. While the cursor is inside a cell, the shortcuts type or do nothing. Press Esc or Enter first.
  • A table. Inside a formatted Excel table the rows belong to the table, and the insert adds a table row. That is usually what you want, but the formatting follows the table.
