Themes

Make the ring yours.

A theme is one small JSON file: colours, a pattern, a glow, a font. Build one here and watch the real ring change as you go, because this preview is the same renderer the application uses. Then keep it to yourself, or send it to everybody.

My theme · dark

Every theme carries both variants and follows whichever one Windows is in. Edit them separately; the one you are not looking at keeps the values it started with.

To use it: put the file in %APPDATA%\RadialDeck\themes and reopen Settings; it appears in the Style list. To share it: "Share it on GitHub" opens the themes repository with your file ready to commit as a pull request.

In the box

Twenty-five themes, and a starting point in each of them.

Pick one to load into the studio above. Each has a dark and a light variant; the previews are rendered by the application itself, not mocked up.

From everyone else

The gallery is a folder in a public repository.

There is no account to make and nothing to sign up for. A theme is a file: open a pull request with your JSON and a preview image, and it lands here for everyone.

How to send yours

  1. Build it in the studio above and press Share it on GitHub. That opens the repository with your file already filled in.
  2. Commit it as a pull request. GitHub walks you through it; you do not need to install anything.
  3. Add a 300×300 preview if you can. Settings shows one, or run RadialDeck.exe --render-themes <folder> and take yours from there.
