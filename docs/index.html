How it works

Three motions. Zero memory.

  1. 01

    Hold

    Press your trigger: Ctrl+Alt+Space, a side mouse button, whatever you like. The ring opens under the cursor in under 50 ms.

  2. 02

    Flick

    Move a few pixels toward a slice. Eight directions, always in the same place, so your hand learns them in a week.

  3. 03

    Release

    Let go. The action fires in the app you were already using: paste, keys, script, launch. No click needed.

What it does

The ring changes with the app. So does what it can do.

App-aware rings

Same trigger, different ring in Outlook, Excel, Explorer, your browser or an RDP session. Conditions match the process name or window title, plain text or regex. Several rings can share a trigger; the first match wins.

Clipboard tricks, instantly

33 built-in transforms in C#: plain text, UPPER, clean tracking from a link, JSON, Base64, slug, Cyrillic to Latin, wrong keyboard layout, word count. Copy, flick, pasted. No PowerShell spinning up.

Files in Explorer

Select a file, flick: extract here, zip, hash, terminal in this folder, convert with FFmpeg or Ghostscript. {file}, {dir}, {name} work in any command, and commands run in the folder you are looking at.

Rings inside rings

Up to eight slices, three levels deep. Rest on a slice and the nested ring opens under your cursor, anchored so it never walks across the screen. Servers → SRV01, DC01. Portals → Entra, Intune, Azure.

  • 985 ready-made recipes for 90+ apps, with a Test button before you add one
  • Macros: keys, waits, text and launches in one slice
  • Mouse triggers: Mouse4, Mouse5 or middle button, with or without modifiers
  • Scriptable from AutoHotkey or a Stream Deck: RadialDeck.exe --menu "Name"
  • Updates itself quietly, like a browser
  • English and Bulgarian interface

Questions

Short answers.

Does it need admin rights?

No. It installs per user, no UAC prompt. An admin can choose a machine-wide install for a whole helpdesk.

What does it send over the network?

Nothing about you. The only request is an optional check for a newer version on GitHub. You can turn it off, and then it makes no requests at all.

What if my hotkey is taken?

RadialDeck notices, falls back to a free combination and tells you. Or use a side mouse button; those are never taken.

Is it like Kando?

Kando is a lovely open-source pie menu. RadialDeck is native Windows, knows the foreground app, reads your Explorer selection and clipboard, and ships with 985 recipes. Try both.

Can I edit the config by hand?

Yes. It is one JSON file in %APPDATA%. Save it and the ring updates immediately; a broken file leaves the previous ring running and reports the line number.
