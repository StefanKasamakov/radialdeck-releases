# RadialDeck

A native Windows radial (pie) menu that knows which app you're in. Hold a key or a mouse button, flick toward a
slice, let go: launch apps, send shortcuts, fix clipboard text, act on the files you selected. 1,180 ready-made
actions for 86 programs, 38 themes, 14 languages. Free for two rings.

**Website:** [radialdeck.com](https://radialdeck.com) · [features](https://radialdeck.com/features.html) ·
[ready rings per program](https://radialdeck.com/for/) · [shared rings](https://radialdeck.com/rings.html)

## Install

<a href="https://apps.microsoft.com/detail/9NDJPDW5DV1N?mode=direct"><img src="https://get.microsoft.com/images/en-us%20dark.svg" alt="Get it from Microsoft" width="200"></a>

- **Microsoft Store** (recommended, no SmartScreen prompt): [RadialDeck by Kasa Labs](https://apps.microsoft.com/detail/9NDJPDW5DV1N)
- **winget:** `winget install 9NDJPDW5DV1N`
- **Direct installer:** `RadialDeck-<version>-Setup.exe` from [the latest release](https://github.com/StefanKasamakov/radialdeck-releases/releases/latest).
  Each release lists the installer's SHA-256. The installed app checks this repository for updates once a day.

Windows 10 1809+ and Windows 11, per user, no admin rights needed.

This repository holds the downloads and release notes; the source code lives in a separate repository.
